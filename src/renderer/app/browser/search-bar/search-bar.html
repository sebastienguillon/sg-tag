Search syntax

beach
names, folders or tags containing “beach” (a tag by its name or an alias, with the tags below it)
"summer trip"
exact phrase
tag:France
tagged France or a tag below it, by its name or an alias; ignores case and accents
tag:=France
tagged France itself only
tag:"Paris (Texas)"
quoted when it holds spaces; two tags cannot share a name, so tell look-alikes apart this way
-tag:draft
a leading minus excludes
type:video
image or video
ext:jpg,png
file extensions (commas mean “or”)
size:>10mb
also <1gb, 1mb..5mb
in:2024/japan
folder path contains
is:untagged
also is:tagged, is:missing, is:offline
is:duplicate
files with an identical copy, side by side (after Find duplicates)
